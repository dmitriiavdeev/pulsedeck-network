# Как пользоваться PulseDeck

[На главную](../README.md) · [English](guide.en.md)

## Начать мониторинг

[Скачайте установщик](https://github.com/dmitriiavdeev/pulsedeck-network/releases/download/v1.1.0/PulseDeck-Setup-1.1.0-x64.exe), установите PulseDeck и откройте приложение. Поддерживается Windows 10 и 11, 64-разрядная версия.

Нажмите Добавить адрес. Для наблюдения за восстановлением сервера оставьте выбранный SSH и порт 22, либо укажите свой SSH-порт. Для других задач выберите тип проверки и укажите IP-адрес, домен или адрес сайта. Для проверки порта также укажите его номер. Сохраните адрес и нажмите Начать мониторинг. Большой список можно загрузить кнопкой Импорт.

Проверка Ping показывает, отвечает ли устройство на сетевой запрос. TCP проверяет доступность выбранного порта, а HTTP / HTTPS — ответ сайта. Для сайта лучше выбрать HTTP / HTTPS: ответ на Ping сам по себе не означает, что сайт работает.

SSH проверяет корректное приветствие службы без логина и пароля. Он не проверяет вход в конкретную учётную запись. Если ранее вы добавили сервер как Ping или TCP, нажмите Изменить рядом с адресом, выберите SSH и проверьте номер порта. История нового типа проверки начнётся заново.

VPN может отвечать на Ping и принимать TCP-соединения до ответа удалённого сервера. Эти результаты не означают, что SSH или сайт уже работают.

## Обновление приложения

Откройте Настройки / Обновления и нажмите Проверить обновления. PulseDeck покажет новую версию и размер загрузки. Нажмите Скачать изменения, затем Перезапустить и обновить. Загружаются только изменившиеся части файлов; адреса, история и настройки сохраняются.

Для перехода с версии 1.0 сначала установите версию 1.1 или новее обычным установщиком. После этого обновления доступны внутри приложения.

## Уведомления

Откройте Настройки и включите нужные уведомления: на рабочем столе, звуковые или в Telegram. Их можно включать и отключать независимо. Для звука доступны 20 мелодий, предварительное прослушивание и регулировка громкости.

Для Telegram создайте отдельного бота через [BotFather](https://t.me/BotFather). Откройте чат с созданным ботом и нажмите Старт. В настройках PulseDeck вставьте токен бота, нажмите Найти чат, выберите чат, отправьте тестовое сообщение и сохраните настройки.

По умолчанию изменение состояния подтверждается двумя последовательными проверками. Так случайная потеря одного ответа не вызывает лишнее уведомление.

## Работа в фоне

Крестик закрывает окно, а PulseDeck продолжает проверять адреса в области уведомлений рядом с часами Windows. Всплывающие уведомления и звуки работают и в этом режиме, если включены в настройках.

Чтобы полностью завершить приложение, нажмите правой кнопкой на его значок и выберите Выйти. Для мониторинга компьютер должен быть включён и не находиться в спящем режиме.

Автозапуск по умолчанию выключен. Его можно включить в Настройки / Основное, чтобы PulseDeck запускался при входе в Windows.

## Если что-то не работает

[Сообщите о проблеме](https://github.com/dmitriiavdeev/pulsedeck-network/issues): опишите, что произошло, и укажите версию Windows и PulseDeck. Не публикуйте токен Telegram или другие личные данные.
