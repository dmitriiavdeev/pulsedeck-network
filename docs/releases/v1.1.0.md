**PulseDeck 1.1: проверка SSH и обновления внутри приложения.**

**[Скачать PulseDeck для Windows](https://github.com/dmitriiavdeev/pulsedeck-network/releases/download/v1.1.0/PulseDeck-Setup-1.1.0-x64.exe)**

Windows 10 и 11 · 64-разрядная версия · Бесплатно

Новая проверка SSH сообщает о восстановлении ответа службы сервера. Простое принятие соединения VPN больше не считается успехом в этом режиме. SSH выбран по умолчанию при добавлении адреса; для существующего адреса его можно выбрать через Изменить.

В Настройки / Обновления можно проверить новую версию, скачать только изменившиеся части файлов и установить их с перезапуском. Адреса, настройки и история сохраняются.

Для перехода с версии 1.0 один раз воспользуйтесь установщиком выше. Дальнейшие обновления доступны внутри приложения.
