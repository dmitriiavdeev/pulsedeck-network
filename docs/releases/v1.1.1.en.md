# PulseDeck 1.1.1: SSH checks and in-app updates

**[Download PulseDeck for Windows](https://github.com/dmitriiavdeev/pulsedeck-network/releases/download/v1.1.1/PulseDeck-Setup-1.1.1-x64.exe)**

Windows 10 and 11 · 64-bit · Free

The new SSH check reports when the server's SSH service responds again. A VPN accepting a TCP connection is not enough for this check to pass. SSH is selected by default for new monitors; existing monitors can be changed through Edit.

In Settings / Updates, check for a new version, download only changed file chunks and restart to install. Your monitors, settings and history are preserved.

To upgrade from version 1.0 or 1.1.0, use the installer above once. Subsequent updates are available inside the app.
