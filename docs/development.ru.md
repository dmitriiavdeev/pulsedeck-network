# Разработка PulseDeck

[На главную](../README.md) · [English](development.en.md)

Эта страница описывает работу с исходным кодом. Для установки готового приложения используйте ссылку на главной странице.

## Локальный запуск и проверки

Для разработки нужны Windows x64, Node.js 22 или новее и .NET Framework 4.8.

```sh
npm ci
node scripts/prepare.mjs
npm test
npm run test:ui
npm start
```

`prepare.mjs` готовит значки, звуковые сигналы и вспомогательную программу для Ping. Модульные проверки выполняются командой `npm test`, проверки интерфейса — `npm run test:ui`.

## Устройство приложения

PulseDeck использует Electron для настольного окна и системной интеграции. Интерфейс написан на HTML, CSS и JavaScript. Проверки сети выполняются в основном процессе; доступ к ним из интерфейса проходит через ограниченный интерфейс `preload`.

| Файл или каталог | Назначение |
| --- | --- |
| `app/main.cjs` | Окно, трей, уведомления, автозапуск и обработчики запросов интерфейса |
| `app/engine.cjs` | Цикл мониторинга и очередь проверок |
| `app/core.cjs` | Проверка входных данных, состояние адресов и подтверждение изменений |
| `app/probes.cjs` | Проверки Ping, TCP, SSH и HTTP / HTTPS |
| `app/native/PingProbe.cs` | Вспомогательная программа для Ping в Windows |
| `app/storage.cjs` | Сохранение настроек и истории |
| `app/telegram.cjs` | Доставка уведомлений в Telegram |
| `app/ui/` | Интерфейс, стили и переводы |
| `installer/` | Установщик и удаление приложения на C# / WPF |

Переводы интерфейса находятся в `app/ui/translations.json`, установщика — в `installer/translations.json`. При изменениях поддерживайте обе языковые версии.

## Данные и поведение

Настройки и история хранятся в `%APPDATA%\PulseDeck\pulsedeck.json`. Токен Telegram шифруется для учётной записи Windows и не включается в экспорт. При удалении приложения пользовательские данные сохраняются.

История содержит последние 120 проверок каждого адреса и 1 000 событий. Суммарные счётчики проверок сохраняются отдельно. По умолчанию состояние меняется после двух совпадающих результатов. Число одновременных проверок ограничивается, фиксированного лимита количества адресов нет.

Неотправленные сообщения Telegram остаются в очереди после перезапуска, до 200 сообщений. При неоднозначном сетевом сбое повторная попытка иногда может привести к дублированию сообщения. Смена бота или чата очищает очередь.

## Сборка выпуска

Проверьте и зафиксируйте исходники, отправьте коммит в `origin/main`. Подготовьте архив командой `git archive` и распакуйте его в отдельную чистую папку. Установите зависимости командой `npm ci`, затем выполните `npm run build`, передав полный SHA коммита в `PULSEDECK_GIT_SHA` и SHA-256 архива в `PULSEDECK_ARCHIVE_SHA256`.

Скрипт создаёт установщик, `manifest.json` и `SHA256SUMS.txt` в `release/`. Манифест содержит полный SHA коммита и хеши исходников, файлов приложения и установщика. Установщик проверяет хеши вложенных файлов и создаёт ярлыки для текущего пользователя. Автозапуск включается только по выбору пользователя.

Сборки, установщики и локальные данные не включайте в Git. Исходники распространяются по лицензии MIT; Electron и его компоненты сохраняют собственные лицензии в установленном приложении.

## Иллюстрации и описание

`node scripts/screenshots.mjs` создаёт скриншоты приложения с отдельными демонстрационными данными для каждого языка. `node scripts/preview-installer.mjs` создаёт изображения установщика. Эти команды не используют пользовательские настройки и историю.

Русское описание находится в `README.md`, английское — в `README.en.md`. Тексты выпусков хранятся в `docs/releases/`. При обновлении версии замените ссылки на установщик в обеих языковых версиях.

## Обновление внутри приложения

`app/updater.cjs` проверяет последний стабильный выпуск в GitHub. `app/update-core.cjs` сравнивает локальные файлы с манифестом, повторно использует совпадающие блоки по 1 МиБ и собирает новые файлы во временной папке. `app/update-network.cjs` загружает только необходимые диапазоны по HTTPS; ответ без поддержки диапазонов отклоняется. Хеши блоков и целых файлов проверяются перед установкой.

`scripts/build-update.mjs` создаёт `PulseDeck-update-<версия>-x64.json` и `.pdu`. Публикуйте оба файла вместе с установщиком в выпуске `v<версия>`. Приложение доверяет этому репозиторию GitHub через HTTPS; манифест не имеет отдельной цифровой подписи издателя.

`app/native/UpdateHelper.cs` ожидает завершения приложения, сохраняет прежние изменяемые файлы, устанавливает подготовленные и перезапускает PulseDeck. При ошибке копирования выполняется откат. Рабочие данные пользователя не входят в пакет обновления. Подготовленные файлы и резервные копии находятся в папке `updates` профиля приложения.

SSH-проверка обменивается идентификационными строками по [RFC 4253, раздел 4.2](https://www.rfc-editor.org/rfc/rfc4253#section-4.2). Она подтверждает ответ службы, но не выполняет обмен ключами, проверку ключа хоста или вход в учётную запись.
